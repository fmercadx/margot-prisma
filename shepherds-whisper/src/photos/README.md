# Photographs

Drop image files straight into this folder. The file name (without its
extension) is the slot it fills:

| File name          | Where it appears                          |
| ------------------ | ----------------------------------------- |
| `hero-living-room` | The large photo beside the headline       |
| `about-porch`      | "A household, not a facility", left tile  |
| `about-hands`      | "A household, not a facility", right tile |
| `day-dining`       | "A day here", under the intro             |
| `private-room`     | The house gallery, large tile             |
| `living-room`      | The house gallery                         |
| `dining`           | The house gallery                         |
| `garden`           | The house gallery                         |
| `bathroom`         | The house gallery                         |

`.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. Any slot without a file
renders a designed placeholder instead, so the page is never broken while you
are still collecting photographs — add them one at a time as you get them.

Shoot wide, in daylight, with the lights on. Aim for the long edge to be around
2000px; the build fingerprints and compresses them from there.

**Get written consent from a resident or their legal representative before any
photograph showing them goes on the site.** A resident's image and the fact of
their residence are protected health information.
