Read a tri-merge the way an underwriter reads it

Load a MISMO CREDIT_RESPONSE XML, or one consumer-disclosure PDF per bureau. The file is parsed, normalized across repositories, and run through the rules engine — middle score, credit-limit gaps, one-bureau late marks, eligibility arithmetic — and you get ranked findings plus a draft analysis report.

Nothing is uploaded Python runs inside this tab as WebAssembly. The credit file is read by your own browser and never crosses the network — there is no server to send it to. Close the tab and every trace of it is gone.
